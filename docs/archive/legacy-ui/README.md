Isi dan keputusan historis dipertahankan; perpindahan diverifikasi dengan SHA-256 sebelum tautan relatif disesuaikan. Dua manifest asli berada di `tmp/cleanup-20261008/historical-documents-before-link-rebase.json` dan `historical-documents-remainder-before-link-rebase.json`; salinan byte asli tersedia dalam checkpoint sumber serta Git.
